# 원탭 AI 팀 회의실 (OneTap AI Team Room)

27호기. 안건 하나를 넣으면 **기획 · 개발 · 마케팅 · 재무** 리드가 차례로 발언하고, **교차검수(Auditor)** 가 앞선 네 답변의 숫자·출처·담당을 다시 봅니다. 남는 것은 대화록이 아니라 **액션 체크리스트와 회의록**입니다.

- 서버 없음 · 회원가입 없음 · 결제 없음
- 무료 모드에서 외부 요청 0건 (폰트까지 로컬)
- 8개 기본 부서 + 내가 추가한 부서 · 부서별 기록 LocalStorage 저장
- 기본 팀 5명 (기획·개발·그로스·재무·교차검수) · 역할 최대 10명
- 🎬 AI HQ 라이브 관제 & 회의실 — 2.5D 아이소메트릭 오피스 8개 워크스테이션 + 중앙 회의실 소집 + CEO 결재 HUD
- EN / KO 토글 (영문은 USD 기준)
- Pro(BYOK): OpenAI · Gemini · Claude 키를 브라우저에만 저장하고 직접 호출

## 왜 이 앱인가

혼자 회의하면 결정이 미뤄지고, AI 한 명에게 물으면 반대 의견이 없습니다. 이 앱은 **역할을 나눠 순서대로 발언시키고, 마지막 역할이 앞선 답변을 검수**하게 합니다. 검수자는 다음을 반드시 지적합니다.

1. 근거 없는 숫자 (예: "전환 2%"의 출처가 없는 경우)
2. 예산과 연결되지 않은 실행 수치 (예: "방문 3,062명"에 채널 단가가 없는 경우)
3. 담당이 역할 이름으로만 적힌 액션
4. 개인정보·권한 관련 액션이 빠진 경우 (안건에 해당 신호가 있을 때)
5. 개발 답변의 API 계약·테스트·롤백 근거가 빠진 경우

CFO는 예산·객단가·전환율로 회수 필요 방문 수를 실제로 계산하고, Auditor는 그 계산을 다시 해 확인합니다. 개발 리드(DEV)는 기능보다 인터페이스 계약, 테스트 케이스, 배포·롤백 절차를 먼저 고정합니다.

## 부서(방)

기본 8개: **전체 · 기획 · 개발 · 디자인 · 영상 · 마케팅·홍보 · 영업·제휴 · 운영·CS**.
`+ 부서 추가`를 누르면 이름과 한 줄 설명을 넣어 내 부서를 만들 수 있습니다.

- 부서마다 안건·발언·액션을 따로 보관하고, 새로고침해도 유지됩니다.
- 부서를 바꿔도 다른 부서 기록은 남습니다. `방 초기화`는 그 방만 지웁니다.
- 직접 추가한 부서는 `부서 삭제`로 지웁니다. 기본 8개는 지워지지 않고, 최소한 전체 방은 항상 남습니다.
- 부서가 9개를 넘어도 상단 방 바는 가로 스크롤로 한 줄을 유지합니다(모바일 390px 동일).
- 새 부서에도 그 부서 이름을 넣은 샘플 안건 3종이 자동으로 생기고, 무료 엔진과 Pro 프롬프트가 그 부서 이름을 회의 맥락에 넣습니다.
- 모든 설정은 `onetap.teamroom.v1` 하나에 저장됩니다.

## 🎬 AI HQ 라이브 관제 & 회의실

KPI 4카드 아래에 붙는 한 장짜리 관제 패널입니다. 새 기록을 만들지 않고 **아래 3단 회의창·체크리스트·회의록이 쓰는 같은 기록을 읽어서** 그립니다. 그래서 좌석·모니터·게이지가 본문과 어긋나는 일이 없습니다.

- **부서 모니터 (8분할, 기본 8 + 내가 추가한 부서)**: 왼쪽·오른쪽 두 벽에 2열로 붙는 **2.5D 워크스테이션**입니다. 벽·창·바닥 그리드·우드 책상·듀얼 모니터·의자·화분·머그가 아이소메트릭 SVG로 그려지고, 그 부서를 맡은 AI가 **네모난 블록 머리·블록 몸통·양팔이 있는 로블록스 스타일 캐릭터**로 책상 앞에 앉아 타자를 칩니다. 상태 배지(`STANDBY` / `ON AIR` / `보고 완료`)와 그 부서의 액션 결재 현황, 마지막 발언 한 줄이 카드에 붙습니다. 회의 전이거나 담당이 없는 부서는 **빈 의자와 꺼진 모니터**로 남습니다.
- **🏛️ 중앙 회의실**: 역할 5명(추가 역할 포함)이 **입체 원목 타원 테이블** 위아래 좌석에 앉습니다. 각 좌석은 의자에 앉은 블록 캐릭터 + 이름표이고, 회의 전에는 `빈 자리`(빈 의자), `회의 시작`을 누르면 캐릭터가 나타나며 `착석`으로 바뀝니다.
- **ON AIR**: 지금 발언 차례인 좌석과 그 역할의 담당 부서 모니터에 빨간 비콘과 `ON AIR`가 켜지고, **한 줄 실시간 말풍선**(발언 첫 줄)이 중앙 테이블 위에 뜹니다. 발언자는 자리에서 살짝 들썩이며 손을 들고, 담당 책상의 캐릭터는 타자를 칩니다. 발언이 끝나면 좌석은 `보고 완료 ✓`, 모니터는 `보고 완료`로 식습니다.
- **아트 원칙**: 외부 CDN·Three.js·이미지 파일 없이 **순수 CSS 3D + 손으로 계산한 아이소메트릭 SVG**만 씁니다(외부 요청 0건 유지). 캐릭터는 역할별로 머리·헤어/모자·안경/헤드셋·셔츠·넥타이/후드가 다르고, 애니메이션은 `prefers-reduced-motion: reduce`에서 모두 멈춥니다.
- **CEO 결재 HUD**: `오늘 처리 안건`(오늘 발언이 있는 방 수) · `완료 액션`(이 방 완료/전체) · `결재율 %` + 게이지. 오른쪽 체크리스트를 누를 때마다 0.5초로 차오릅니다.
- 역할 → 모니터 대응은 `data.js`의 `ROLE_ROOM`(기획·개발·마케팅·운영·전체)에서 정합니다. 참여하지 않는 부서(디자인·영상·영업 등)는 `STANDBY`로 남습니다.
- 판단은 `core.js`의 `liveSnapshot()` 한 곳에서만 합니다(순수 함수, DOM·시계·저장 없음). 1440px는 모니터 2×2 벽 + 중앙 회의실이 한눈에, 390px는 2열 미니 모니터 + 컴팩트 회의실로 접힙니다.

## 무료 모드 (기본)

1. 부서를 고르고 안건을 적거나 샘플 3종 중 하나를 누릅니다.
2. `회의 시작`을 누르면 다섯 역할이 **순서대로** 발언합니다(약 0.4~0.5초 간격).
3. 발언이 나올 때마다 오른쪽 체크리스트에 액션이 쌓입니다(5역할 × 3건 = 15건).
4. 발언에 `답글`을 달면 그 역할이 내 말을 인용해 다시 답하고, 액션을 하나 추가합니다.
5. `이어서 토론`은 2라운드를 엽니다. 2라운드는 새 안건을 꺼내지 않고 적용 시점과 중단 기준만 정합니다.

무료 엔진은 안건에서 숫자(예산·전환율·기간·목표)와 위험 신호(개인정보·결제·계약·보안)를 읽고, 도메인(출시·가격·성장·유지·채용·인프라·보안·재무·운영·콘텐츠·기획·디자인·영상·영업)에 맞춰 문장을 조립합니다. 같은 입력은 같은 결과를 냅니다(결정적).

## Pro 모드 (BYOK)

`Pro` 또는 톱니 버튼 → 제공자 선택 → 모델 이름 → 키 입력 → `저장하고 Pro 사용`.

- 키는 `localStorage`(`onetap.teamroom.pro.v1`)에만 저장됩니다. 화면에는 앞 4자·뒤 4자만 보입니다.
- 호출은 브라우저 → 제공자 API로 직접 갑니다. 이 페이지에는 백엔드가 없습니다.
- 5개 역할을 **연속 호출**하며, 뒤 역할은 앞선 발언 전체를 프롬프트에 받습니다. Auditor는 특히 네 답변의 숫자를 인용·재계산하도록 지시됩니다.
- 프롬프트에는 고른 부서 이름(직접 추가한 부서 포함)과 참석 역할이 들어갑니다.
- Pro 라운드는 기본 5역할(기획·개발·그로스·재무·검수)만 호출합니다. 직접 추가한 역할은 무료 모드 라운드에서 발언합니다.
- 응답은 `관점/제안/리스크/요청/액션` 형식으로 파싱되어 무료 모드와 같은 카드로 표시되고, `액션:` 줄은 체크리스트가 됩니다.
- 401/429/네트워크/형식 오류를 구분해 보여주고, 실패한 발언부터 다시 시도할 수 있습니다.
- 기본 모델: OpenAI `gpt-4o-mini`, Gemini `gemini-2.5-flash`, Claude `claude-sonnet-4-20250514`. 모델명은 자주 바뀌므로 404가 나면 발급 페이지의 현재 이름으로 바꾸세요.
- OpenAI·Claude는 브라우저 직접 호출을 막는 경우가 있습니다. 그때는 Gemini 또는 자체 프록시를 쓰세요.

## 내보내기

`회의록` 카드에서 Markdown · TXT · JSON으로 저장하거나 Markdown을 클립보드로 복사합니다. 파일에는 부서 이름, 안건, 참석 역할, 모든 발언, 답글, 체크 상태가 들어갑니다. 파일 이름은 `onetap-team-room-{부서}-{YYYYMMDD}.{확장자}`입니다.

## 검증

```bash
node test.js       # 단위 테스트 743건 (data/core/i18n + 파일 위생)
python3 uitest.py  # headless Chrome E2E 282건 (데스크톱 1440×900, 모바일 390×844)
```

`uitest.py`는 로컬 HTTP 서버를 띄우고 실제 Chrome을 돌립니다. 확인 항목: 부팅 외부 요청 0건, 콘솔 에러 0, 가로 넘침 0, 8개 부서 전환·기록 유지·새로고침 유지, `+ 부서 추가`와 저장·삭제, 5인 릴레이 발언, 검수 4건 인용, 답글, 체크리스트 토글·영속, MD/TXT/JSON 다운로드, 복사, EN/KO 전환, 역할 이름 변경·추가, Pro 3개 제공자 모의 호출(5회 연속)·오류 표시·키 저장/삭제, 대비 검사, 그리고 **관제 패널**(모니터 8대 렌더·`회의 시작` 시 `ON AIR`·좌석 소집·회의 종료 `보고 완료`·결재 게이지 상승·새로고침 뒤 좌석 복원·모바일 2열). 스크린샷은 `work/`에 저장합니다.
